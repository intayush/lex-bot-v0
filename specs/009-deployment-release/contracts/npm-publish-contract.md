# Contract: NPM Publish (Changesets)

**Owner**: Deployment & Release (`009-deployment-release`)
**Source of Truth**: §9.7 row 3, §9.10, §6.2.

## Published Packages

| Package | Path | Purpose |
|---|---|---|
| `@legal-chatbot/widget` | `packages/widget` | NPM widget for React/Next.js sites (§6.2) |
| `legal-chatbot-crawl` (or `@legal-chatbot/crawl`) | `packages/crawler` | CLI crawler for `npx legal-chatbot-crawl` (§3.3, §9.7 row 3) |

The internal packages (`@legal-chatbot/api`,
`@legal-chatbot/dashboard`, `@legal-chatbot/shared`) remain
`private: true` — they are NOT published.

## Changesets Workflow

1. **Engineer adds a changeset** with the change:
   ```bash
   pnpm changeset
   ```
   Selects affected public packages + bump type (patch / minor
   / major) + writes a human-readable summary.

2. **Changeset file committed** to `.changeset/<random>.md`.

3. **PR with the changeset merges to main**. Changesets'
   GitHub Action (or manual `pnpm changeset version` →
   commit → PR) opens a "Version Packages" PR consolidating
   all pending changesets:
   - Bumps `package.json` versions.
   - Generates `CHANGELOG.md` entries.
   - Removes the consumed `.changeset/*.md` files.

4. **Version PR merges to main** → `.github/workflows/release.yml`
   triggers:
   - Runs full PR checks (CI stages 1–6).
   - Runs `pnpm changeset publish` → publishes packages to
     npm; tags git commit.

## release.yml

```yaml
name: Release
on:
  push:
    branches: [main]
jobs:
  release:
    if: contains(github.event.head_commit.message, 'Version Packages')
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          registry-url: 'https://registry.npmjs.org'
      - run: pnpm install --frozen-lockfile
      - run: pnpm build
      - run: pnpm changeset publish
        env:
          NPM_TOKEN: ${{ secrets.NPM_TOKEN }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

(Trigger condition is the conventional Changeset commit
message; alternative is a manual workflow_dispatch.)

## Required Secrets

| Secret | Purpose |
|---|---|
| `NPM_TOKEN` | npm publish auth |
| `GITHUB_TOKEN` | git tag + push (auto-provided) |

## Package Metadata Requirements

Each published package's `package.json` MUST have:

```jsonc
{
  "name": "<scoped-or-flat>",
  "version": "0.x.x",
  "description": "<one-liner>",
  "license": "<choose one>",
  "repository": { "type": "git", "url": "..." },
  "type": "module",
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": { ... },
  "files": ["dist", "README.md"],
  "publishConfig": { "access": "public" },
  "private": false
}
```

For the crawler, additionally:

```jsonc
{
  "bin": { "legal-chatbot-crawl": "./dist/cli.js" }
}
```

For the widget, additionally:

```jsonc
{
  "peerDependencies": {
    "react": "^18.0.0 || ^19.0.0",
    "react-dom": "^18.0.0 || ^19.0.0"
  }
}
```

## CHANGELOG Format

Generated by Changesets per package:

```markdown
# @legal-chatbot/widget

## 1.2.0

### Minor Changes

- abc1234: Add prefers-reduced-motion support to the typing indicator.

## 1.1.0

### Patch Changes

- def5678: Fix focus trap on Escape key.
```

## Verification

After a release:

1. `npm view @legal-chatbot/widget version` → matches the new
   version.
2. `npx legal-chatbot-crawl@latest --help` → invokes the new
   crawler.
3. The git tag (e.g., `@legal-chatbot/widget@1.2.0`) exists in
   the repo.

## Constitution Compliance

- Constitution VII: Changesets is the binding versioning tool.
- Constitution I (MVP-First): only the two binding public
  packages are published; internal packages stay private.
